foxreach is installed

Agents on this computer, like Claude Code or Codex, can now ask to use this browser. When one does, this appears under the address bar:

Allow
It can work in this browser until it disconnects. Tick the box and it won't ask again.
Refuse
It gets nothing.

Agents only see the tabs they open themselves and the ones you share with them. To pause them or change what they can do, click the foxreach button in the toolbar.
