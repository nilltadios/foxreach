foxreach is installed

Agents on this computer, like Claude Code or Codex, can now ask to use this browser. When one does, a small foxreach window opens in front of whatever you are doing:

Allow
It can work in this browser until it disconnects.
Always allow
Agents with this name won't have to ask again.
Refuse
It gets nothing.

When an agent wants a site that is not on your list yet, the same window asks about the site.

Agents only see the tabs they open themselves and the ones you share with them. To pause them or change what they can do, click the foxreach button in the toolbar.
